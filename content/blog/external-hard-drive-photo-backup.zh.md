移动硬盘是最常见的照片“备份”——也是最常被遗忘的。两年前拷过一次、之后一直躺在抽屉里的硬盘，算不上真正的备份。下面介绍如何用好移动硬盘，让它真正保护全家的照片。

<!--more-->

## 选硬盘

- **容量：** 至少是现有图库的 2–3 倍，留出几年的增长空间。
- **桌面盘还是便携盘：** 3.5 寸桌面盘自带电源，适合一直连接的备份；2.5 寸便携盘适合轮换带去异地。
- **固态还是机械：** 固态更快、更抗摔；机械盘每 TB 更便宜。存照片两者都行。
- **买两块。** 一块盘就是单点故障。

## 文件系统

| 文件系统 | 适合 |
| --- | --- |
| NTFS | Windows |
| APFS | Mac |
| exFAT | Windows 和 Mac 之间来回用 |

已经有文件的硬盘不需要重新格式化。Windows 和 Mac 上的 Lomorage 支持系统支持的所有文件系统；树莓派上支持 vfat、exfat、ext2/3/4、hfsplus 和 ntfs（见[常见问题](/zh/faq/)）。

## 按日期整理，而不是靠记忆

“新照片”“手机备份2”“最终版”这样的文件夹，很快就乱成一团。请按**年/月/日**整理。Lomorage 会自动完成——备份的原图以普通文件形式保存在按日期命名的文件夹里，即使不用 App，硬盘内容也一目了然。

## 别再手动拷贝

手动拷贝只在你记得的时候才有效。更好的做法：

1. 把硬盘接到一台通常开着的电脑、NAS 或[树莓派](/zh/blog/2026/11/25/raspberry-pi-photo-server/)上。
2. 安装 [Lomorage](/zh/)，选择这块硬盘作为存储——App 会推荐剩余空间最大的硬盘。
3. 手机会按你设定的时间通过 Wi-Fi 自动备份。

## 加上第二份

再接一块硬盘作为**冗余备份**：

- 树莓派：[冗余备份指南](/zh/blog/2019/12/24/raspberrypi-hd/)
- Windows + 网络硬盘：[把 WD MyCloud 设置为冗余备份盘](/zh/blog/2023/02/22/set_wd_as_backup/)
- macOS：在 LomoAgent 设置中配置冗余备份

然后再在家以外保留第三份——参见 [3-2-1 原则](/zh/blog/2026/11/24/321-backup-family-photos/)。

## 防止丢失的好习惯

- **每隔几个月检查一次：** 从每块硬盘打开几张新旧照片和视频。
- **安全弹出**后再拔线。
- **让硬盘休眠。** Lomorage 支持硬盘休眠，需要时自动唤醒。
- **及时更换老硬盘。** 升级时参考[数据迁移指南](/zh/blog/2023/03/02/migrate_from_pi_win/)。
- **保持凉爽、避免磕碰**——高温和震动会缩短硬盘寿命。
