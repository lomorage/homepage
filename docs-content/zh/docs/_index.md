Lomorage 把家庭照片保存在你自己掌握的设备上。先选择最像你家情况的路径；复杂的技术选项，可以以后再了解。

## 最简单的开始方式

使用一台还有足够空间的 **Windows 电脑或 Mac**。先安装电脑端照片助手，再在手机上安装 LomoMobile。建议先备份少量照片，确认状态并打开几张原文件，再逐步备份整个相册。

- [设置 Windows](/zh/docs/Installation/lomorage-service/installation-win/)
- [设置 macOS](/zh/docs/Installation/lomorage-service/installation-osx/)
- [安装手机应用](/zh/docs/Installation/lomorage-client/)

## 家里已经有存储设备？

Lomorage 也可以运行在 **群晖 NAS、树莓派、Linux 服务器、Docker 或 Unraid** 上。这些指南更适合熟悉对应设备的用户。

- [查看所有电脑与服务器方案](/zh/docs/Installation/lomorage-service/)
- [从旧硬盘导入照片](/zh/docs/Installation/lomorage-importer/)

## 完成第一次备份以后

请检查备份状态，在存储设备上打开几张原文件，并为无法替代的照片保留另一份独立副本。本地硬盘也可能发生故障。

接下来可以了解[家庭使用、分享与日常管理](/zh/docs/Usage/)，或查看[常见问题](/zh/faq/)。
