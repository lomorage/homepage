通过 LomoMobile 连接家里的 Lomorage 相册，备份新照片，也可以随时翻看全家人的回忆。

## 选择你的手机

- [iPhone 与 iPad](/zh/docs/Installation/lomorage-client/installation-ios/)
- [Android](/zh/docs/Installation/lomorage-client/installation-android/)

初次设置时，让手机与 Lomorage 存储设备连接同一个家庭网络。家人也可以扫描配对二维码登录，不必手动输入服务器地址和密码。

## 使用浏览器

[网页应用](/zh/docs/Installation/lomorage-client/installation-web/)可以在电脑上浏览和上传照片，也能通过 Inbox 查看家人分享的照片与视频。

连接成功后，先尝试备份少量照片并确认能够打开，再逐步处理整个相册。
