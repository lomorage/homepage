Once the first backup works, Lomorage can become a shared home for the family while each person keeps a separate account.

## Give everyone their own account

Create a separate account for each person. Kids or grandparents can scan a pairing QR code to sign in without typing the server address and password.

## Share without duplicating the whole library

Share selected photos and videos with family members. They can find received items in the web Inbox while the original library stays organized under its owner.

## Keep the library understandable

Browse by date and use [custom views](/docs/Usage/customized-view/) when you want another way to organize folders and collections. Use the [import tool](/docs/Installation/lomorage-importer/) for photos already stored on hard drives or memory cards.

## Treat backup as a routine

Check that a backup completed and open a few originals. Keep another independent copy of irreplaceable photos, and review [updates and maintenance](/docs/Usage/Update/) for devices you manage yourself.
