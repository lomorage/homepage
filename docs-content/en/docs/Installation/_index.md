Lomorage has two parts: a photo assistant on the device that stores your library, and LomoMobile on each phone that backs up or browses photos.

## 1. Choose where photos will live

For most families, start with [Windows](/docs/Installation/lomorage-service/installation-win/) or [macOS](/docs/Installation/lomorage-service/installation-osx/). If you already manage a NAS or home server, browse [all supported server platforms](/docs/Installation/lomorage-service/).

## 2. Add the phone app

Install LomoMobile for [iPhone and iPad](/docs/Installation/lomorage-client/installation-ios/) or [Android](/docs/Installation/lomorage-client/installation-android/). Keep the phone and storage device on the same home network for initial setup.

## 3. Try a small backup

Start with a few photos. Confirm they appear in the library and open correctly before backing up everything. Installing the apps alone does not mean the photos have finished backing up.

Already have photos on a computer or USB drive? Use the [import tool](/docs/Installation/lomorage-importer/).
